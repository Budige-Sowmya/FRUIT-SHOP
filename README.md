The Fruit Shop Management System is a console-based Python application designed to simulate the operations of a fruit shop. The system supports two roles — Customer and Shopkeeper — each with distinct functionalities. Customers can view available fruits, add or remove items from their cart, and generate a bill with the total amount payable. Shopkeepers can manage inventory by adding new fruits, updating quantities, modifying spoiled stock, or removing unavailable fruits.
This project efficiently demonstrates the use of Python control structures, lists, loops, and conditional statements to handle real-world operations such as inventory management, billing, and data updates dynamically. It provides an interactive and user-friendly experience through menu-driven options.
